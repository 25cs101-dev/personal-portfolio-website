# Personal Portfolio Website

A very simple personal portfolio website built with plain HTML, CSS, and JavaScript. It introduces me, shows my skills, and lists my projects.

## Features

- Five sections: Home, About Me, Skills, Projects, Contact
- Smooth scrolling when clicking the navigation links
- Menu button that opens and closes the navigation on mobile screens
- Clean, simple design that works on both mobile and desktop
- Placeholders for email, GitHub, and LinkedIn that can be replaced later

## Technologies Used

- HTML
- CSS
- JavaScript

No frameworks, libraries, backend, database, or APIs are used.

## Project Structure

```
personal-portfolio-website/
│
├── index.html   (page structure and content)
├── style.css    (colors, layout, and responsive design)
├── script.js    (menu button behavior)
└── README.md    (project description)
```

## How to Run

1. Download or clone this repository.
2. Open the `personal-portfolio-website` folder.
3. Double-click `index.html` to open it in your web browser.

No installation is needed.
